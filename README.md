# BypassCam

BypassCam is a professional camera application for Android that allows the use of external USB microphones for audio recording during video capture. It is specifically optimized for hardware compatibility on devices like the Motorola Moto g04.

## Features
- Real-time Camera preview.
- Photo and Video capture using CameraX.
- Automatic detection and permission handling for USB audio devices (Microphones).
- Front and Back camera selection.
- Modern Jetpack Compose UI.

## Architecture
This project follows Clean Architecture principles, ensuring separation of concerns between hardware logic (USB, Camera Manager) and the user interface (Jetpack Compose).
